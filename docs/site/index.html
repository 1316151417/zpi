01 / PHILOSOPHY

极简，是有意识的取舍。

不把客户端变成一套庞大的 Agent 平台。少一层抽象，少一组工具，少一点选择噪声。

01

四个工具就够开始

读、写、精确编辑、执行命令。搜索、测试、网络请求交给已有的命令行程序，不为每件事增加专用工具。

readwriteeditbash
02

不内置 MCP、REPL、Browser Use

Agent 已经能写脚本。需要浏览器自动化，就让它编写控制脚本并通过 bash 执行，而不是挂上一整组常驻浏览器工具。

需要本机具备相应运行环境和依赖。

03

不做复杂的任务编排

没有子 Agent 或后台任务编排。保留清晰的对话和执行过程，让你知道当前在做什么，方便检查，也方便修改客户端本身。

可选用户提问能力默认关闭，内核仍只有四个基础工具。

↳

不内置，不等于不能做。 Agent 可以通过 bash 使用已有程序。右侧网页预览是供你查看结果的界面，不是给 Agent 的 Browser Use 工具。

02 / MODEL FREEDOM

工具精简，模型选择不精简。

用你已有的账号和 API。根据任务换模型，而不是为了模型更换整个工作流。

↔同一任务，继续对话

自由切换模型

预置 ChatGPT、DeepSeek、智谱、MiniMax、MiMo，也能自定义提供商、模型 ID 和能力参数。支持启用、排序、刷新模型目录与思考程度配置。

Chat CompletionsResponsesAnthropic Messages

运行中也能切换：当前执行使用原配置，后续消息使用新选择。跨模型保留文本与工具历史，专有推理签名只用于对应模型。

◎OAuth 套餐授权

接入你的 ChatGPT

通过浏览器登录并授权 ChatGPT 套餐访问。不用复制网页 Cookie；使用授权令牌调用 Responses API，自动续期并获取账号模型目录。

系统加密可用时加密保存凭据，否则仅保留在本次应用内存。可用模型、额度和访问资格取决于账号；不承诺「绝不封号」。

＋不绑定供应商

国产模型，也能自己配

预置常用国产提供商的套餐和按量 API 配置。其他兼容服务或本地模型，可填写地址、API Key 和模型参数接入。

按服务端能力选择协议。高级配置支持自定义推理等级与 CEL 参数映射；兼容性取决于服务端，不宣称支持任意模型。

$_已有配置，无需重填

启动时识别预置提供商的 API Key，初始化尚未添加的配置。已经手动设置过的提供商，不会被自动发现覆盖。

A FEW CLEAR BOUNDARIES

把边界也说清楚。

没有遥测，是否意味着所有内容都不出本机？

不是。会话与配置在本机保存，但使用云端模型时，所需上下文仍会发送给你选择的提供商。ZPI 不采集产品遥测，不能替第三方模型服务承诺数据处理方式。

ChatGPT 接入能保证不封号吗？

不能。ZPI 使用 OAuth 登录与套餐访问授权，不要求复制网页会话 Cookie，也不以绕过风控为目标。账号规则、额度和访问资格由 OpenAI 决定，请遵守提供商条款。「待验证」的预置模型也不代表账号一定可用。

辅助对话是不是子 Agent？

不是。它由你手动开启，继承创建时的稳定上下文，独立回答后续问题，不自动承接主任务。它与主任务共享目录，并非文件隔离；如要隔离修改，可使用独立任务的 Git 工作树。

不支持 Browser Use，为什么有网页预览？

网页预览是供人查看结果的桌面面板，不是 Agent 的控制工具。需要自动化时，Agent 可以写浏览器控制脚本，通过 bash 运行；本机须具备对应依赖。

能在脚本里复用 ZPI 的内核吗？

可以。仓库提供小型 zpi-coding-agent SDK，复用模型、四个工具与会话能力。查看调用示例 ↗。开发需 Node.js 24 和 npm，具体步骤见 README。
