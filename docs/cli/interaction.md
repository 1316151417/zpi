# 终端交互

CLI 服务于当前目录的短任务、同目录续聊和管道调用。交互界面以 Pi 为参照，斜杠入口沿用 zpi 能够执行的 Claude Code 命令。

## 启动与续聊

| 调用 | 行为 |
| --- | --- |
| `zpi`、`zpi "问题"` | 在 TTY 打开输入框。带问题时直接提交。空启动、查看帮助或选择模型后退出，不产生历史。 |
| `zpi -c` | 继续当前实际目录最近一条有用户输入的 CLI 会话。无记录或被占用时说明原因。 |
| `zpi -r [id]` | 无 ID 时从当前目录列表选择，有 ID 时直接恢复。列表显示会话名称或首条输入摘要，以及最近活动时间，无需登记项目。 |
| `zpi -p "要求"` | 接受位置参数和管道输入。两者都有时以一个空行分开，构成同一条提示。默认临时运行。 |
| `zpi -c -p "问题"`、`zpi -r <id> -p "问题"` | 用户明确要求续写，才将本轮追加到对应的 CLI 会话。打印模式不打开选择器。 |
| `-m`、`--model <provider/model>`、`--effort <档位>` | 从已配置的服务为本次调用选模型和推理档位。 |
| `--help`、`--version` | 无需模型、凭据或 TTY。无 TTY 的普通交互调用提示使用 `-p`。 |
| `zpi auth [login [provider] [--method key\|oauth]]` | 不指定服务就打开选择器。指定服务和方式可直接开始连接，例如 `zpi auth login anthropic --method key`。 |
| `zpi auth list`、`zpi auth switch <provider> <account>`、`zpi auth logout` | 查看 CLI 已连接的账户，切换服务的当前账户，或交互选择要移除的连接。 |
| `zpi models`、`zpi models --default <provider/model>` | 列出当前账户已启用的完整模型名，或设置新会话的默认模型。这些管理操作均不写会话。详见[模型配置与账户](models.md)。 |

`-c` 与 `-r` 互斥。`-p` 的 stdout 只输出本轮最终可见回答并换行，错误和诊断走 stderr。纯命令返回该命令本轮的结果，例如 `zpi -c -p "/compact"` 输出压缩反馈。运行失败返回 1，参数错误返回 2，用户中断返回 130。下游管道关闭时退出并清理临时资源。首版的脚本接口到此为止。

## 输入与显示

| 用户动作 | 终端反馈 |
| --- | --- |
| 启动 | 左上角只显示黄色的 `ZPI`。其下是对话区，输入框和状态栏固定在底部。 |
| 写提示 | Enter 提交，Shift+Enter 换行，终端不能区分时使用 Ctrl+J。支持中文、多行粘贴和上下键回看本次输入。Ctrl+R 可搜索本次终端最近 100 条不同输入。Ctrl+S 暂存，空输入时再按取回。Ctrl+G 用 VISUAL 或 EDITOR 编辑，未设置时使用 vi。 |
| 引用资料 | `@` 选当前目录下的文件或子目录，使用原生文件引用。Ctrl+V 可粘贴终端主机剪贴板中的图片，删除草稿里的图片标记即可移除。图片统一走 zpi 原有校验和模型能力检查。没有附件管理页。 |
| 查找命令 | 输入 `/` 可选择 Skill、文件命令及内置命令。Tab 采纳候选，Esc 关闭。命令用法在提交前可见，例如 `/rename <名称>`。完整 Skill 名在草稿中高亮，可立即追加要求。整段粘贴的斜杠正文按原文处理。 |
| 阅读对话 | 用户消息使用整行底色。模型正文按 Markdown 流式渲染，供应商返回的可见思考默认以弱色斜体展开，工具按实际调用顺序展示。有可读思考时，Ctrl+T 可隐藏或恢复显示，偏好保存在 CLI 私有配置。只有签名、加密内容或用量的轮次不生成思考正文。 |
| 查看工具 | read、edit、write、bash 使用各自的预览。Ctrl+O 查看完整输出或内核提供的修改差异。生成时可以先编辑下一条草稿，等本轮结束再提交。 |
| 中断或退出 | Esc 或 Ctrl+C 在主界面中断当前轮，保留已产生的结果。弹层中的 Esc 仅关闭弹层。空闲且输入为空时 Ctrl+D 退出。 |

一个输入框、一个可复用的选择列表和工具详情就能完成上述操作。业务问题通过对话回答。工具按 zpi 原有执行语义运行，终端不加逐步确认。运行中草稿驻留本进程内存。

## 斜杠命令

| 入口 | 依据 |
| --- | --- |
| `/help`、`/hotkeys`、`/exit`、`/clear`、`/resume` | 帮助在可关闭的面板中显示快捷键和命令，Tab 切页，Esc 返回输入框。Skill 明细由 `/` 或 `/skills` 浏览。`/hotkeys` 将键位表显示在当前终端的对话滚动区。`/clear` 打开新草稿，旧历史仍可用 `-r` 找到。 |
| `/copy [N]`、`/rename 名称` | 复制倒数第 N 条可见回答（默认最近一条，需终端支持 OSC 52）。可在首条消息发送前给会话命名，首次有效提交才把名称随会话写入历史。 |
| `/login [提供商]`、`/logout`、`/model`、`/effort`、`/fast`、`/context` | 连接提供商、搜索并选择模型、设置推理或加速档位、查看上下文。选模以本次会话为准，选择器内 Ctrl+S 可同时更改默认。 |
| `/compact [要求]` | 直接交给内核压缩当前上下文。沿用现有语义，不提供独立的 `/summary`。 |
| `/init [要求]` | 用户显式调用时，复用已有 `zpi.project-init` 声明和基础工具维护工作区 AGENTS.md。无需创建项目记录或加载桌面插件宿主。[既有命令声明](../../packages/builtin-plugins/src/index.ts) |
| `/<Skill 名> [要求]`、`/skills`、已有文件命令 | 直接输入或从 `/skills` 选择都将 Skill 名放在编辑行。可追加要求、修改或删除，再按 Enter 发送。内置和文件命令保留原名，重名 Skill 在候选中显示为 `/$名称`。[公共配置与资源](resources.md) |

例如默认输入 `/review` 会得到未知命令提示。用户输入“帮我看看这个 diff”会作为普通提示交给现有 zpi 工具处理。非交互模式只执行可完整从文本确定的操作，遇到需要选择器的命令直接说明用法，不等待键盘。[原生命令](../../packages/coding-agent/src/core/commands.ts) · [会话 API](../../packages/coding-agent/src/core/agent-session.ts)
