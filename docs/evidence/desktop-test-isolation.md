## 系统层观察证据

观察器源码在 `tests/probes/macos-desktop-observer.m`，可重复运行入口为 `scripts/observe-desktop-tests.mjs`。它只读 NSWorkspace、CGWindowList 和 NSPasteboard.changeCount，不操作其他应用或系统设置。

| 观察批次 | 样本数 | 记录的 Electron 启动次数 | 测试窗口可见样本 | 测试应用前台样本 | 剪贴板计数 |
| --- | ---: | ---: | ---: | ---: | --- |
| 修复前单例退出 | 105 | 1 | 9 | 0 | 保持不变 |
| 修复后隐藏窗口/辅助对话重复 | 1196 | 14 | 0 | 0 | 保持不变 |
| main 合入后清理五场景 | 575 | 5 | 0 | 0 | 保持不变 |
| 扩展功能组合（含启动失败） | 2544 | 17 | 0 | 0 | 3821→3822 |
| 浏览器视图独立重跑 | 322 | 3 | 0 | 0 | 3822，保持不变 |
| 最终清理及后代退出核对 | 374 | 5 | 0 | 0 | 3822，保持不变 |
| 最终隐藏窗口两轮 | 409 | 6 | 0 | 0 | 3823，保持不变 |

修复前采到的是测试 PID 所有的 1200×800 原生窗口，alpha 从约 0.006 到 1，出现在退出阶段约半秒，说明隐藏参数和 Electron 的窗口状态断言不足以证明没有屏幕干扰。去掉后台退出的 `setEnabled(false)` 后，上述批次没有再采到这一窗口。

这些是有限时长、50 ms 间隔、本机平台、记录到的测试 PID 的观察结果，不是对所有时间间隔和平台的绝对保证。办公期间其他应用或用户操作会改变剪贴板计数，变化批次不能直接认定是测试造成，也不能声称其剪贴板始终不变。静态检查和运行时拦截补充覆盖未被采样捕获的调用路径。

观察日志留在入口输出的 `zpi-desktop-observation-*` 目录；它们是验证产物，二进制和观察进程会清理。guardians 不是操作系统沙箱：宿主/guardian 同时被强杀、断电、未观察到的瞬间脱离进程不属于可保证的回收范围。未采用按进程名杀应用、切换桌面或修改系统设置的办法。
