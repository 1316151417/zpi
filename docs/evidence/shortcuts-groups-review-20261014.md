## 确认并修复

1. **收起当前分组后普通新建无法看见草稿。** 普通新建（快捷键、侧栏/窗口按钮、搜索命令）现在与组头新建共用展开规则，仅对仍有效的草稿导航展开。不会因为后台回复/刷新而展开用户主动收起的分组。ZCode 的 contextual draft 路径见 `WorkspaceGroupedTasksSection.tsx:810–837`。
2. **分组拖动碰到自身后预览回跳。** 例如 A/B/C → B/A/C，命中移动后的 A 自身标题曾恢复 A/B/C。忽略自身及本组成员目标，保留最后有效落点。对应上游 `WorkspaceGroupedTasksSection.tsx:325–338,1435–1476`、`workspace-grouped-tasks/view.ts:438–446`。新增回归修复前失败、修复后通过。
3. **长分组名的两处样式遗漏。** 移动菜单中的名称加单行省略并与色点左对齐；挂到 body 的拖拽浮层使用独立截断样式，保留计数宽度。参考 `task-context-menu-content.tsx:73–85` 与 `group-drag-overlay.tsx:28–33`。这是源码确认的样式差异，不冒充截图验证。
4. **自定义停止键被编辑器吃掉。** 有效的 Shift+Command/Ctrl+Enter 曾插入换行且无法停止。非 Escape 的停止键现在先于编辑器处理，按住不重复触发；裸 Escape 保留局部取消优先语义。回归运行实际 hook 和 MentionEditor handler，不依赖 Electron。
5. **隐藏辅助对话问题误挡全局快捷键。** 保留挂载的隐藏提问卡带有 role=dialog，原全文档选择器将它当成可见弹窗。统一可见性判断供 workspace/composer/stop 复用；真正可见的菜单、对话框和设置仍阻断命令。
6. **快速 A → B → A 新建吞掉最后一次选择。** 按项目/分组去重仅覆盖草稿获取/创建；每次导航保留独立意图，复用已有 selection generation。迟到创建/资源结果不抢回选择或焦点；仅有效导航返回草稿 ID 供展开逻辑使用。
7. **失败分组操作丢弃有效初始读取。** 只有成功应用的分组变更才使旧刷新失效，失败命令不会把首屏分组状态及折叠偏好清空；成功命令回包以最新已应用请求为准，防止旧回包回退。
