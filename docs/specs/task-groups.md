# 任务分组

参考 ZCode `aac4755666d09fdcd70272fcf063c077a639015f` 的实际源码：`WorkspaceGroupedTasksSection.tsx`、`workspace-grouped-tasks/{group-item,task-row,types,colors,view}.tsx/ts`、`buildGroupedTaskViewFromSessions.ts`。授权范围是任务分组，不引入 ZCode 的定时任务、闲时运行、远程工作区、反馈上报或工作流系统。

## 产品与持久化

- 保留原有默认项目视图；顶部改为「分组 / 项目」28px 胶囊，项目筛选中保留时间线。分组跨项目，任务仍使用自己的工作目录，搜索仍覆盖原任务。
- 胶囊沿用 ZCode 的半透明 surface 外壳与 background 选中层，在 ZPI 分别映射为 `--color-fill` / `--color-bg`，不可把白色面板 token `--color-surface` 用作外壳；保留 2px 内边距、24px 按钮与 12px 图标，未选中项 hover 只加深文字。
- 窄侧栏中隐藏胶囊内的装饰图标并缩减按钮横向内边距，保留「分组 / 项目」文字和操作按钮的 24px 尺寸，避免排序、新建及展开入口被压缩或裁切。
- 分组模式在胶囊右侧 4px 处始终保留 24px 全部展开/收起按钮。无分组时显示禁用的「展开全部」；有分组时全部展开则显示「收起全部」，存在折叠则显示「展开全部」，tooltip 与图标同步。新建分组位于工具栏右侧，排序入口紧随其后；分组与项目的折叠状态互不影响。
- 分组与未分组任务在顶层混排。任务默认按更新时间排序，可在工具栏切换创建时间或手动排序，偏好独立于项目视图并在本地保存。时间排序只派生组内、顶层任务的显示顺序，保留分组位置和完整手动顺序；运行中任务优先规则与项目视图一致。每个任务至多属于一个分组。
- 创建默认名称「New Group」（与上游持久化默认值一致），灰色，插入顶部并进入内联命名和颜色选择。支持重名；空名称取消修改，Enter 提交（避开 IME），Escape 取消，失焦提交。
- 七色：gray/red/orange/yellow/green/blue/purple，使用现有 Lucide Hash/箭头/新任务图标。组头 32px，色标 20px / Hash 12px，菜单色点 10px，内容左缩进 16px + 边线 + 8px，任务行 28px。
- 移动到分组菜单的色点与名称左对齐；长名称保持单行省略，不撑高或硬裁菜单。分组拖拽浮层的长标题独立截断，保持计数可见，不依赖侧栏祖先样式。
- 点击组头以 200ms grid/透明度过渡折叠/展开，关闭后卸载内容；全部收起/展开独立于项目；始终显示可见任务数量；空组保留新建/拖入入口。右键菜单：新建任务、重命名、更改颜色、取消分组并删除。删除只解散分组，保留任务及内容。
- 长列表顶层和组内都在超过 80 项时虚拟化，overscan 12；展开组标题滚出上边界时吸顶，拖拽时停用吸顶和 tooltip。
- 任务右键菜单支持移至其他组、移出分组。手动排序下支持移到所在层级顶部和组间/组内/顶层拖拽，保持全量顺序；时间排序下隐藏移到顶部并禁用拖拽，菜单提示切换手动排序。菜单移入组追加到保存顺序末尾，移出放原组后，显示仍遵循当前排序。
- 拖拽重排后命中活动任务/分组自身（含本组目标）时保持最后有效预览和落点；不得回跳拖拽起始顺序。
- 置顶在统一置顶区，保留分组归属/顺序；归档不展示且保留归属，恢复返回原组；删除任务清理引用。重命名/运行状态不影响手工顺序。
- 分组内新建使用当前工作目录并放组首；分组视图的常规新建继承当前可见任务分组；当前任务位于独立置顶区时回到根级。草稿按项目和分组复用，避免把其他组草稿挪走。
- 分组视图的新建快捷键、侧栏/窗口按钮及搜索中的新任务命令，在创建或复用分组草稿时展开所属组，与组头新建保持一致；只在明确新建时展开，不因任务运行或刷新覆盖用户手动收起的状态。
- 主进程是分组唯一持久所有者，`task-groups.json` 原子写入；复用 IPC 和 Zustand，不修改核心 SDK/会话内容格式。旧安装缺少文件时从原任务按创建时间降序产生顶层列表。操作按命令更新完整结构，不能以可见行覆盖隐藏的置顶/归档成员。

## 验收

- 旧任务兼容、重复命名、空名称/IME、重启读回、组色/折叠保留。
- 移入/移出/跨组、顶层混排、组内与组间拖拽、组头上下边界、空组、折叠组的目标语义。
- 删除分组保留任务；归档/置顶恢复保持归属；任务切换与菜单、颜色按钮、拖拽不误触发。
- 三视图切换不改变数据；置顶快捷键继续使用现有置顶栏可见顺序。
- 浅色/深色胶囊的外壳、选中、hover 与尺寸符合 token；空分组、部分折叠、全部展开/收起、删除最后一组及来回切换视图时，工具栏按钮位置和可用状态正确。
- 执行相关单测、完整单测、check、build；可用时运行隐藏 Electron 集成测试并截图。无法运行的环境或未对比的像素细节如实记录。

## 新任务草稿导航

### 规则与状态所有者

- Renderer store 继续按项目和分组复用草稿；同一目标并发创建只能生成一个会话。
- 每次新建任务或手动选择任务都是独立导航意图，以用户最后一次意图为准。草稿创建去重不能吞掉后来的导航。
- 创建、刷新、草稿保存和资源读取均可异步完成；较早操作完成后不能重新选择任务或抢回输入焦点。
- `newSession` 仅在本次导航仍有效且当前已选中目标草稿时返回其 ID；被新意图覆盖时返回 `undefined`。调用方只能为该有效目标展开分组。

### 验收

- A 组资源读取未结束时，依次新建 B 组、A 组任务，最后选择 A；读取全部结束后仍为 A。
- 同组创建未结束时重复点击，只创建一个草稿，最后一次调用可完成导航。
- 新建 A 尚在创建或资源读取时，手动选择 B，A 的迟到结果不能抢回选中状态或焦点，也不能返回可供调用方展开的 ID。
- 较早的 A 创建慢于 B 时，B 保持选中，A 草稿仍被保留用于后续复用。
- 新建任务完成后，隐藏保留的辅助问题弹层不阻止输入框回焦；可见弹层仍阻止抢焦。

### 分组刷新失败边界

- 只有成功落地的分组变更才使在途旧读取失效。失败命令不能阻止初始分组数据加载，也不能使已保存的折叠偏好被空列表清除。
- 成功变更仍需阻止较早的刷新覆盖；并发变更的回包以最新成功命令为准，较早成功回包不能回退状态。
