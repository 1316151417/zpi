# 任务列表与项目分组对齐

参考本地 ZCode `3c5b227649371507ddc4eb46ac5133afe6db1cab` 的 `project-sidebar`。范围是任务列表头部、三种组织视图、项目顺序、移除展示语义和分组拖动校验。沿用 ZPI 单目录项目、主进程 SessionHost/TaskGroupsStore 和 SQLite；不引入远程项目、多目录 roots、自动化或插件商店。

- 顶部导航保留新建任务；搜索移至「任务列表」标题右侧。标题栏位于列表滚动区外，顶部边线、12px 上留白、左右 8px、标题左右 10px、24px 图标按钮及 4px 间距按原版布局。
- 标题栏从左到右为标题、分组操作（仅分组模式）、搜索、筛选视图。分组操作顺序为收起/展开全部、新建分组；项目收起/展开全部移到项目分区的新建入口左侧，使用原版 ListChevrons 图标。分区标题本身承担折叠和拖动，不保留独立 Grip 按钮；启动距离 6px，只限制横向位移，落点显示同款蓝线。
- 筛选视图是单选菜单，固定「按项目 / 按分组 / 最近更新」，分别使用 Folder、Hash、Clock，右侧 Check 表示选择。去掉胶囊切换器、时间排序分区和创建时间选项。沿用原偏好 key 和 organizeBy，旧 sortBy 失效；切换不改变项目归属、分组成员或手工顺序。
- 项目视图保持运行优先、再按更新时间排序；最近更新包含所有未归档主任务（含置顶和已移除项目的任务），严格按更新时间排序，不重复展示独立置顶区。时间标题只使用更新时间和本地日历边界。
- 按项目和未归类任务各 5 条分页，每次增加 5；最近更新 20 条，每次增加 20。空态统一为「暂无任务」，按原版 34px 内容缩进和 subtlest 颜色；项目标题到内容 4px、分区间 12px。不新增空项目列表引导文案。
- 项目标题由文件夹和名称组成一个展开/排序触发器。PointerSensor 的启动距离为 6px，KeyboardSensor 使用 sortableKeyboardCoordinates；保留垂直位移并禁用缩放，目标上/下显示原版蓝线和圆点。
- 新项目插入顶部；重新打开/恢复同一真实目录复用原 ID 和排序槽。主进程验证完整可见 ID 集合后在同一 SQLite 事务保存顺序，隐藏项目保留排序槽。刷新、运行、重命名和重启不能改变已保存顺序。
- 「从侧栏移除」只隐藏项目，任务仍保留 projectId 和 cwd，不伪装成未归类任务。其任务继续出现在最近更新、搜索、分组及置顶中。恢复归档任务不重新显示项目；用户重新添加目录才恢复项目。移除不删除目录、会话或分组。
- 分组拖动携带拖动开始时的 sourceGroupId；主进程按当前组织态校验来源、目标组和锚点。过期来源/锚点拒绝，保持持久状态，客户端报告失败并重读。菜单命令继续以当前状态执行；不由可见行重写整个组织结构。

验收覆盖三视图切换与重载、搜索唯一入口及快捷键、头部滚动固定、浅深色/窄宽侧栏、项目指针/键盘排序及重启、隐藏项目语义、来源/锚点失效、隐藏置顶/归档成员和草稿分组不丢失。截图用隔离隐藏 Electron，视觉对照直接渲染原版头部组件和样式。
