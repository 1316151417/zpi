# 审查面板

以 ZCode `3c5b227649371507ddc4eb46ac5133afe6db1cab` 的 `GitPane.tsx`、`GitPaneChangeCard.tsx`、来源选择控件和中文文案为视觉、交互参照。

- 新标签页的「审查」打开独立审查标签，默认「未暂存」，不显示文件 Diff 徽标。来源按未暂存、已暂存、全部分支更改、上一轮更改排序；每个标签保存自己的选择，任务切换不串来源。
- 工具栏内边距 12px，来源选择和刷新高 32px。空态使用 32px 文档图标，标题与说明居中；上一轮空态文案与参考一致。
- 文件行高 32px，显示文件图标、文件名、淡色父路径、增删行数及展开箭头；初始全部折叠，只允许一个文件展开，展开文件标题置顶。长列表虚拟化，diff 展开时读取，跨文件查找才补读其他文件，刷新使缓存失效。普通修改必须读取完整 before/after，并使用与 ZCode 一致的 MultiFileDiff，默认 unified、bars、word-alt、line-info、github-light/github-dark、12px、WASM 高亮和共享 worker 池。未修改区的行数、上下方向/全部展开按钮由同版本库生成，必须能真实展开首部、中间和尾部内容。大文件或全文不完整时才走 PatchDiff(simple)；锁文件、深 hunk、元信息等按参考 patchDiffPreview/helpers 的同一规则降级为最多 800 行轻量预览。轻量预览不做语法高亮，行号从 1 连续计数，遵循 48px gutter / 12px code padding。
- 右键提供系统文件管理器、复制绝对/相对路径和在文件树中显示。删除文件禁用系统打开，文件树动作复用现有目录加载和祖先展开。
- 文件展示与参考一致：父路径保留末尾斜杠；来源切换立即清除展开状态；右键使用“在文件管理器中打开”。来源选择使用 14px 箭头、悬停/键盘聚焦边框反馈，滚动按钮高 22px。
- 界面设置中的审查代码预览提供参考的十种主题、12–20px 字号、行号和换行选择，保存在现有界面偏好中；富 Diff 接入深浅代码主题和字号，轻量预览额外接入行号、换行，遵循参考组件的实际消费范围。共享 worker 池同步主题变化。旧偏好缺少新字段时使用 GitHub 深浅主题、12px、有行号、不换行。
- 查找有完整快照时按 before 再 after 索引，与参考相同，未修改文字在两侧各计一次；局部 patch 只索引剥离头部和 marker 的内容。
- 未暂存列表先展示已跟踪文件，再展示未跟踪文件，最后展示冲突文件，各组按相对路径排序；冲突行显示 +0/-0，不进入已暂存来源。没有可审查文本的未跟踪空文件、二进制、超过 1 MiB 或不可读文件不占用列表；已跟踪二进制仍保留降级提示。
- 未暂存含未跟踪文件；暂存与工作区各自独立。分支比较遵循参考，使用上游与 HEAD 的三点比较，没有上游时为空。只显示当前工作目录子树；Git 命令有超时/输出上限，禁用外部 diff/textconv，路径按字面处理。
- 上一轮来源使用 ZPI 现有会话索引和工具快照，只读取最新轮次，不能退回整个任务累计变更；非 Git 目录同样支持。参考源码当前尚未接入上一轮投影，ZPI 保留自身已可用的快照能力。
- 主进程负责 Git 和会话快照，preload 只暴露严格类型 IPC；renderer 只持有选择和显示投影。`readReviewDiff` 返回 patch、beforeContent、afterContent 及 availability，不能仅用 patch 代替完整内容；两侧任一不可读时保留 patch 并关闭 MultiFileDiff。请求按来源隔离，迟到结果不能覆盖新来源。手动刷新、当前任务工具完成/轮次结束、窗口恢复焦点触发刷新；隐藏标签不请求。原生 Git 监听沿用参考的 60 秒防抖，监听由 Git 解析出的 git-dir/common-dir，以及非 Linux 上的 workspace 递归目录；来源切换或隐藏会清理监听。
- 聊天摘要和工具卡片打开的文件 Diff 保留既有文件导航和预览路径，不进入仓库审查模式。
- 共用侧栏标签头提供搜索总览、当前任务最近关闭的八个可恢复标签，以及关闭当前／其他／所有标签菜单。恢复审查保留来源，恢复浏览器和终端通过既有生命周期重建；不同任务不能看到或恢复彼此的关闭记录。选择结果后清空搜索词。
- 完整视图由工具栏或 Cmd/Ctrl+Shift+F 切换，按任务恢复当前显示面和浮动编辑器状态，保留原侧栏比例。主对话和输入框保持同一实例，草稿、Diff 展开和滚动不因切换丢失；完整对话作为额外标签显示。浮动编辑器支持收起、展开、最小化、七处拖动吸附、运行状态与新回答预览。快捷键接入现有可配置分发，尊重自定义和清空设置，不覆盖冲突组合。

验收包括暂存/未暂存同文件分离、重命名、删除、新建、二进制、特殊文件名、子目录作用域、上游比较、非仓库、最新轮快照、来源迟到请求隔离、展开/折叠、刷新、右键和跨文件查找。桌面测试使用隔离启动器和假模型服务。

2026-10-22 补齐验收：必须用有三个相隔修改点的 Java 文件验证首部 14 行、中间 13 行的折叠条，点击后检查真实正文及行号；不能以新建文件或空态截图代替普通修改的验收。对照包含纯重命名、mode-only、增删文件、文本/结构化文件、深行号、超限与二进制、刷新/来源切换缓存和失效请求。
