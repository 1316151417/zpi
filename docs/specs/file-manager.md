# 文件管理与无项目工作目录

参考 ZCode `3c5b227649371507ddc4eb46ac5133afe6db1cab` 的本地文件能力。

- 右侧新标签页按文件、浏览器、终端、审查、辅助对话排列；辅助对话遵循现有可用条件，已有整个任务的审查标签时隐藏重复入口。加号创建真实新标签；打开内容替换当前新标签的位置，其他任务的标签和折叠状态保持独立。
- 文件标签初始名为“文件”，选择文件后更新为文件名，文件夹图标保持不变。各标签彼此独立，导航仅更新发起标签的预览，不改任务归属和活动标签；目录目标在打开时固定，任务切到 Git 工作树后，旧标签继续浏览原目录，新标签使用新的工作目录。迟到读取不得覆盖新导航、恢复已关闭标签或激活其他任务的面板。
- 文件页统一 40px 标头，面包屑与文件操作通过 portal 进入该行；预览在左，目录在右。目录默认 192px，最小 160px、最大面板宽度 60%，支持鼠标和键盘调整，使用与 ZCode 相同的 `react-resizable-panels` 4.10.0 保存分栏比例及折叠前宽度。小于 384px 时只显示目录或预览，选中文件临时收起目录；返回宽屏恢复用户偏好。显隐偏好以 cwd 为键保存并由同目录各标签共享。
- 浏览目录包含 dotfiles，目录优先、名称排序；仅加载根和已展开目录。单子目录链按物理路径深度压缩，符号链接不参与自动链加载。手动刷新覆盖根和全部已加载/展开目录，失败保留旧缓存；搜索索引与懒加载缓存分离。
- 监听根、显式展开目录和压缩目录行所代表的已展开末级目录。折叠释放句柄，关闭标签、renderer 导航或退出释放全部句柄。刷新有目录级与工作区级版本校验，监听变化 300ms 合并，最多两个目录并发刷新。
- 目录行高 28px，采用虚拟列表、连续层级引导线、组合吸顶目录和原生 scroll 同步遮罩。选中框、hover、字体、图标和颜色沿用 ZCode 对应样式与素材。
- 搜索复用 ZPI 的 `@` / 快速搜索候选及 basename、相对路径、绝对路径 fuzzy 打分，最多显示 1000 个匹配项；清空恢复懒加载树。点击搜索目录返回树并逐级展开祖先。
- Git 状态显示 M/A/D/R/U，ignored 文件弱化，目录显示后代聚合圆点，修改优先。deleted 虚拟文件可选中和复制路径，不能预览、拖拽或外部打开。非 Git 目录隐藏变更过滤。
- 右键提供打开、打开方式、HTML 内置浏览器、系统文件管理器、复制绝对/相对路径、添加到聊天；拖拽引用采用与 `@` 一致的 Markdown mention，不导入文件内容或发起模型请求。
- 新建无项目草稿使用 `~/.zpi/workspace/draft-<session UUID>`，cwd 写入任务元数据和 transcript。重新选择草稿、重启、辅助对话、子智能体和显式继承 cwd 的任务复用已有路径；读取现有任务不创建目录。现有任务记录的 cwd 保留，项目任务使用原有项目目录。删除任务不递归删除工作目录。快速对话继续使用其独立的既有基点。

范围不包含远程项目、多目录 roots、应用插件市场或文件编辑器的新功能。文件内容继续由已有的文本、Markdown、SVG、PDF、Office、演示文稿和媒体预览组件负责；此处的候选扫描与预览类型限制沿用 ZPI 原有实现。
