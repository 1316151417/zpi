# 文件浏览、预览和备注

在右侧新标签页选择“文件”，或点击聊天里的文件引用，可在应用内检查结果。文件和单文件 Diff 共用预览与目录容器。

## 文件树

目录按文件夹优先、名称排序，包含隐藏文件。展开才加载后代，连续单子目录可压缩显示。搜索与 `@` 文件候选使用同类排序；大目录可继续扫描，结果超限或部分路径不可读会提示。

Git 项目展示修改、新增、删除、重命名和冲突标记，支持只看变更文件。删除文件可复制路径，但不能预览、拖入或外部打开。目录监听随着展开、折叠、关闭标签而申请和释放。

可拖动分栏或手动收起目录，显隐偏好按 cwd 共享。窄面板仍保留可调整双栏，选择文件不会自动收起目录。标签记住自己的工作目录，导航只替换该标签内容。

## 支持的预览

| 类型 | 能力 |
| --- | --- |
| 普通文本、源码 | 代码显示、换行、行号定位、行备注 |
| Markdown、SVG | 预览与源码切换 |
| Mermaid | 图表渲染 |
| HTML | 文件页显示源码；显式浏览器入口用于查看网页 |
| 图片、音视频 | 图片显示、原生播放控件 |
| PDF | 分页、缩放，本地资源和分段读取 |
| DOCX、DOC | 本地文档渲染 |
| XLSX、XLSM、XLS | 工作表切换 |
| PPTX | 缩略图、页码、缩放、元素选择、导出 PDF |

旧 `.ppt` 不支持。无效、过大或无法读取的文件显示受控错误，不保证所有格式特性都与原始 Office 应用一致。

## 行备注与引用

源码左侧加号或行号拖选创建备注，选择范围内需要有非空白代码。备注可以留空；添加后进入当前主任务或辅助对话的草稿，不修改文件、不自动发送。

Esc 取消，Command/Ctrl+Enter 添加。预览标记和输入框引用同步；评论组可以逐条移除或全部移除，普通文字引用保留。发送时携带路径、行号、代码和用户备注。

## 打开和交付卡片

普通点击在应用内预览；Command/Ctrl+点击文件使用系统默认程序，网页使用系统浏览器。预览右上“使用默认程序打开”独立于项目工具栏的编辑器偏好。

模型回复可能生成文件或 localhost 网站卡片。卡片需满足解析、文件存在性及格式规则，Markdown/HTML 还需要本轮实际文件变更。支持的文件不会因为在回复中被提到就无条件产生卡片。

PPTX 自动打开仅发生在当前观察到的成功运行结束时，历史恢复不会自动弹出。PDF 导出通过保存对话框选择目标，取消不会报成失败。
