# 搜索任务、文件和当前内容

ZPI 有跨任务搜索、工作区文件搜索和当前内容查找。选择正确入口可以减少需要加载的历史与文件。

## 快速搜索

默认 Command/Ctrl+K 打开统一入口，按范围查找任务、工作区文件和常用操作。

任务搜索包含未归档主任务的标题和对话正文，隐藏项目的任务仍可出现。结果提供匹配片段，选择后打开任务并定位；归档历史通过归档入口管理。

工作区文件搜索按 basename、相对和绝对路径排序，与 `@` 和文件树搜索共用规则。扫描可以分批继续；“仍未扫描”“匹配超过上限”“路径不可读”是不同状态。结果数量有限不意味着只检查固定的前一批文件。

关闭入口或更改查询会取消旧扫描，旧结果不覆盖新查询。文件树清空搜索后回到懒加载目录。

## 当前任务查找

默认 Command/Ctrl+F 查找当前任务内容，支持前后命中导航和高亮。较早命中可触发分页或挂载，不要求先手动滚动到历史顶部。

普通正文按实际 Markdown 可见文字搜索；思考、工具结果和纯压缩轮不作为普通对话正文索引。流式和动态内容使用相应的实际显示路径。

已打开审查面板时，查找当前来源的文件差异；单文件 Diff 的搜索只覆盖该文件，聚合变更入口可以跨文件查找。

## 常见疑问

- 搜索不到被删除任务：删除会清理其派生搜索数据。
- 结果很多但屏幕高亮有限：界面限制同时绘制的普通命中数量，完整计数和导航仍保留。
- 文件搜索还没完成：使用继续搜索，不要把首批候选当成全部工作区。
- 旧文件不存在：历史补丁仍可能可查看，当前文件预览会报告缺失。

原理：[历史索引、工作区扫描和 DOM 高亮](../internals/search.md)。
