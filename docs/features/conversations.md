# 对话操作

任务是持久对话及其工作目录、模型选择和执行历史的组合。一条用户消息可以触发多次模型请求与多批工具。

## 发送、排队和立即发送

空闲时 Enter 发送，Shift+Enter 换行。回复过程中普通发送把输入加入当前任务队列。队列支持编辑、删除、调整顺序、立即发送和暂停后的继续。

Command/Ctrl+Enter 优先处理当前草稿：先验证输入，再停止当前回复并发送；已有队列保留，之后继续处理。空草稿时发送队首，没有队列则不操作。主对话和辅助对话共用这套规则。

输入框保留尚未提交的文字、引用和附件。发送失败时保留可重试内容；若用户已经开始编辑新草稿，迟到失败不会覆盖它。自定义命令排队时不执行 Shell，实际派发才准备命令。

应用重启后，遗留队列会暂停并保留输入，需用户恢复；不会因重启直接重跑命令。执行和持久化细节见[输入队列](../internals/input.md)。

## 停止和重试

停止中止当前请求及所属前台执行。已完成的写文件和命令结果保留，停止不是撤销。桌面后台命令有[独立生命周期](background-terminal.md)。

模型长时间无有效输出时显示等待信息，可使用“重试”重新请求。工具已执行的结果会保留，不要求模型重新执行同一工具。自动恢复和手动重试的差别见[失败恢复](../internals/recovery.md)。

## 编辑消息、分叉和回退

消息操作允许编辑用户输入、从历史位置分叉，或按已有文件快照回退。分叉拥有新的任务历史，后续对话独立；除显式新工作树等目录操作外，复制历史不意味着复制整个工作区。

编辑会重建该位置之后的有效历史。文件是否保持当前内容或随回退改变，由操作的工作区选项决定。回退会检查文件当前状态；发现外部修改时展示冲突，不能把历史快照当成无条件覆盖许可。

分叉复制受控附件，使子任务不依赖父任务的附件生命周期。对工作区外部文件的引用仍指向外部文件，不会自动备份整个目录。

## 能力和模型何时生效

新任务首次发送时保存提问、子智能体、联网、记忆及相关指令配置。之后更改全局开关不会给旧任务重新增加能力；联网服务停用等请求时检查仍然有效。

模型可以在任务中切换，已开始的执行继续使用原快照，后续输入使用新选择。主任务和辅助对话选择独立。

## 历史与任务操作

较早内容按页加载，搜索命中可以继续定位旧历史。压缩后原始记录仍可保留，模型使用摘要及保留后缀。复制对话和会话路径用于分享内容或排查，但内容可能包含项目材料，应按实际用途处理。

归档隐藏任务并保留历史；恢复重新显示。删除触发任务数据和受控产物清理，不递归删除工作目录。运行中的任务应先停止再归档。
