# 自定义命令

自定义命令把常用提示词保存为 Markdown，通过 `/名称` 调用。它支持参数、技能引用和显式发送时的 Shell 片段。

## 创建和调用

在“设置 → 命令”选择用户范围或当前项目范围，新建名称、描述、参数提示和正文。用户命令保存在 `~/.zpi/commands`，项目命令在 `.zpi/commands`。项目同名命令覆盖用户命令，即使项目版本已禁用。

例如创建 `review`：

```markdown
---
description: 检查指定改动
argument-hint: <范围>
---
阅读 $ARGUMENTS，检查错误路径并说明验证方法。
```

输入 `/review 最近一次修改`，选择建议后还需发送。历史保留原始斜杠输入，模型收到展开后的正文。

`$ARGUMENTS` 是参数尾部文本，`$1`、`$2` 等是支持引号分组的位置参数。缺失位置为空；没有占位符时，非空参数附加到正文。替换只做一次，不递归解释插入的参数。

## 元数据

| 字段 | 行为 |
| --- | --- |
| `description` | 描述和搜索 |
| `argument-hint` | 参数提示 |
| `skills` | 发送时加载指定的已启用技能；支持标量、逗号或方括号列表 |
| `disable-noninteractive` | 隐藏建议，仍允许显式调用 |
| `model`、`allowed-tools` | 保留元数据，当前执行链不应用这些覆盖 |

启停开关独立保存。`/init`、`/compact` 是内置命令，不被自定义命令替换。

## Shell 模板

正文中的内联 `!` 加反引号片段或 fenced `!` Shell 块可能执行本地命令。扫描、预览、建议和进入队列都不执行；实际派发时按顺序执行，并把输出插回提示词。

参数不能通过注入新的模板分隔符新增执行片段，但已有 Shell 片段中的参数仍是该命令文本的一部分，应按正常 Shell 使用方式处理。执行失败不会为了重试模型自动重跑副作用。限额与取消见[命令原理](../internals/commands.md)。

## 导入和外部修改

通过命令页的显式导入操作扫描支持的其他客户端目录。选择范围、命令及复制/软链接方式；默认不选中项目，不覆盖同名目标。

复制产生独立文件；软链接跟随源文件更新。编辑软链接命令会显示实际源路径并要求确认；删除只移除本地链接。Windows 无软链接权限时可改用复制，不会偷偷切换方式。

外部编辑通过刷新、窗口重新聚焦或执行前读取生效。过期编辑版本不能覆盖较新的磁盘内容，失败时保留编辑表单。

原理：[存储、导入与展开](../internals/commands.md)。
