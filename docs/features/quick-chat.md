# 快速对话

快速对话是独立临时浮窗，适合随手提问和带入屏幕内容。它不创建正式任务、不写主任务历史，也不加载项目 AGENTS、技能、命令或记忆。

## 打开和新建

| 动作 | macOS 默认 | Windows/Linux 默认 |
| --- | --- | --- |
| 显示或收起 | Option+Space | Alt+N |
| 开始新对话 | Option+Shift+Space | Alt+Shift+N |
| 立即发送草稿 | Command+Enter | Ctrl+Enter |

普通唤起保留当前文字、图片和回答；新建会清空临时会话。可见且聚焦的空白浮窗再次按新建键才收起。有历史、草稿或处理中附件时，新建键创建新会话；重复按键不会在同一次尚未完成的新建流程中反复重置。

紧凑窗随输入内容向上增长，发送后展开。左上加号新建并保留当次展开；空白大窗收起再唤起可回到紧凑状态。Esc 在运行中先停止，再次按才收起；普通隐藏不停止回复。

## 文字和图片

Enter 在空闲时发送，Shift+Enter 换行；输入法候选确认不会误发送。支持粘贴图片、预览和移除、纯图片消息。失败保留草稿，历史含图片时也需要视觉模型。

图片只在临时会话内存中保留，有导入、历史和在途内存预算；移除已发送图片的草稿入口不会删除已有历史引用。新对话释放旧会话图片。

“设置 → 快速对话”配置独立默认模型。配置无效时尝试可用模型的默认选择，没有可用模型则阻止发送并提示配置。

## macOS 内容带入

| 默认快捷键 | 行为 |
| --- | --- |
| Option+Shift+A | 框选截图，Esc 取消 |
| Option+Shift+C | 向当前应用发一次复制，带入新复制的文字 |
| Option+Shift+V | 读取现有剪贴板，图片优先 |

内容追加到草稿，确认后才发送。首次使用可能需要屏幕录制或辅助功能权限。复制未更新剪贴板、没有文字或切换了前台应用时不会使用旧内容。

截图前浮窗收起，临时截图文件在完成、失败或取消后清理。快捷键可以修改、清空或禁用。其他系统默认不绑定这三项采集命令。

## 过期与能力

会话从最后一次被接受的发送开始计时，超过 15 分钟后在下次用户唤起时重置。输出、显示和隐藏不续期；从未发送的草稿不按此规则过期。

快速对话注册 `read`、`bash` 和当前有效联网工具，未注册写入工具、提问或子智能体。只读要求是提示词约束，`bash` 仍可读写本机和联网。默认工作基点为 `~/Documents/ZPI`，首次发送可能创建它；大 Bash 输出也可能落临时文件。
