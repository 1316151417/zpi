# 联网搜索与来源

联网能力提供 `web_search` 和 `web_fetch`。当前桌面网页服务为 DeepSeek，网页凭据与聊天模型凭据独立，因此可以搜索后交给其他聊天模型分析。

## 配置

1. 在“设置 → 联网搜索”填写独立 DeepSeek Key。
2. 保存并启用提供商。
3. 打开页面右上总开关。
4. 新建任务并首次发送，保存这次任务的联网能力。

总开关默认关闭，需要有效且启用的服务。旧会话没有联网能力时，后来打开全局开关不会给它追加工具。关闭服务、删除或替换 Key 会影响后续实际请求，已发出的请求不追溯撤销。

密钥默认遮蔽。点击眼睛才读取临时明文；隐藏、页面切换或窗口失焦后清除显示。只查看不修改保存值。保存时省略 Key 表示保留，移除 Key 是独立动作。

## 使用

在输入中说明需要查询的主题或网页。搜索词或 URL 发送到 DeepSeek，返回资料再随上下文交给当前模型。客户端不自动补入原始完整问题或定位 IP。

过程卡片是单行状态，显示搜索词或抓取目标，不展开完整网页正文。回复旁的“来源”汇总当前轮、该回复之前的成功工具结果，点击可在内置浏览器打开原文。

站点图标来自已记录结果的 `site_icon`，通过主进程受限下载和解码；失败使用默认图标，不把远端地址直接交给页面加载。

## 限制和失败

抓取只接受没有凭据的公网 HTTP(S) 地址。本地地址和私有 IP 字面量会拒绝；本客户端不为上游抓取解析目标 DNS，上游重定向也由服务负责。

排队、网络、重试和读取共用执行期限。额度错误、取消、超限响应或不再有效的凭据会返回失败。网页内容是资料，不能变成系统指令。

联网开关控制专用工具，不限制 `bash` 自行联网。请求限流、输出预算、重试和来源图标边界见[联网原理](../internals/web.md)。
