# 插件

ZPI 的执行内核保留 `read`、`write`、`edit`、`bash` 四个基础工具。提问、联网、子智能体协作、后台命令、记忆、自动标题和任务通知由系统内置插件提供，在“设置 → 插件”按需配置与启停。

桌面工作区另提供辅助对话、工作树、终端标签、文件预览和审查面板，使用入口见各自功能页。

## 系统内置插件

内置插件随应用提供，无需安装。以下是初始默认值；已有安装以当前设置为准。

| 插件 | 能力 | 初始默认 |
| --- | --- | --- |
| 向用户提问 | 注册 `AskUserQuestion`，在对话中收集选项或文字回答 | 启用 |
| 联网搜索 | 搜索与读取公开网页，需在“设置 → 联网搜索”配置服务凭据 | 关闭 |
| 子智能体协作 | 委派 Agent、传递消息、接收结果和管理子任务 | 启用 |
| 后台命令 | 为 `bash` 提供后台执行、输出查询和任务停止 | 启用 |
| 记忆策略 | 选择短记忆或长期记忆，按配置注入上下文或整理来源 | 插件启用，记忆模式关闭 |
| 会话标题 | 为新任务生成标题，保留用户手动命名 | 启用 |
| 任务通知 | 向系统投递任务结束提醒，通知声音可单独设置 | 启用 |

“交互方式”“多工具调用”“文件链接格式”“文件内容复用”“主动推进”贡献给模型的行为指令；“项目初始化”提供 `/init` 命令。这六项也在插件页管理，初始默认启用。

记忆模式、协作提示预设和通知偏好等配置入口仍在对应设置页。插件页与记忆、子智能体、联网搜索、常规页共享同一份设置，快捷入口的改动会同步显示。

## 生效范围

新任务在首次发送时冻结插件版本、选项、指令、命令和工具集合。修改插件开关、记忆模式或协作提示预设会更新后续新任务的默认配置；已开始的任务及其恢复继续使用自身快照。

服务凭据和系统通知偏好仍在实际调用时检查。停用联网服务、删除凭据或关闭系统通知投递，会限制相应操作，不会重写已有任务的插件快照。

关闭后台命令插件后，新任务使用基础 `bash`；关闭协作插件后，新任务不再装配委派工具。两项可以分别启停。后台命令、子任务及应用退出的清理规则见[后台命令与终端](background-terminal.md)和[协作与提问](collaboration.md)。

## 添加本地插件

1. 打开“设置 → 插件”，点击“添加 → 从本地文件夹添加”，选择包含插件清单的根目录。空列表也提供添加按钮。
2. 导入会校验并缓存支持的组件，然后启用插件。导入过程不运行命令钩子、安装依赖或加载任意 JavaScript 入口。
3. 新建任务并首次发送，使用新导入的插件；刷新可重新读取已注册插件的显示状态。

支持复用 Claude Code/ZCode 插件中的命令、技能、Agent 定义及受支持的 command/process 钩子。MCP、LSP、插件 UI、插件市场和自动更新不在当前范围；不支持的组件会明确报错。具体事件和格式见[插件兼容边界](../internals/plugins.md#本地外部插件)。

命令钩子可以运行本机程序，添加前应确认目录来源与脚本内容。更新同一插件只影响新任务，已有任务仍依赖此前冻结的缓存和版本。

## 插件与钩子

插件可贡献指令、命令、工具或生命周期钩子。“设置 → 钩子”展示实际声明的处理器，并提供用户和项目钩子的配置入口。插件自带钩子跟随所属插件启停，列表中只读展示；指令或工具贡献不一定经过钩子。

使用方式见[钩子配置](hooks.md)，实现边界见[内置运行时隔离](../internals/plugins.md#内置运行时隔离)。

## SDK 与独立应用

ZPI 桌面和独立的 [zpi-quick-chat](https://github.com/1316151417/zpi-quick-chat) 共用 TypeScript Agent SDK。公共 SDK 提供工具选择、Agent 定义、插件和 Hook 接口；应用自行选择装配内容，不自动获得 ZPI 桌面的整套内置插件或工作区界面。接入见[SDK 文档](sdk.md)。
