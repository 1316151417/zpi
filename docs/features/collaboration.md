# 辅助对话、子智能体和提问

辅助对话适合用户追问；子智能体适合主 Agent 委派工作；结构化提问让 Agent 等待用户选择或补充信息。

## 辅助对话

在右侧新标签页打开辅助对话。创建时复制父任务已经稳定保存的上下文；父任务运行中可以包含当前用户消息，但不复制尚未完成的助手输出。创建之后不持续同步父任务。

辅助对话有独立模型、消息、输入队列和运行状态。界面只展示自身的新时间线，继承前缀仍可作为模型上下文。关闭或停止它不停止主任务。

它共享父任务工作目录，提示词要求只有用户明确请求才修改工作区。需要目录隔离时使用独立任务的 Git 工作树。

## 子智能体

在“设置 → 插件”启停系统内置“子智能体协作”插件，“设置 → 子智能体”管理 Agent 定义并提供相同插件设置的快捷入口。默认包含 `general-purpose` 和 `Explore`，可新建个人或项目配置，设置描述、提示词、颜色、工具范围、AGENTS 注入及模型选择。它与桌面的辅助对话分别提供能力，插件默认状态与生效范围见[插件](plugins.md)。

协作插件默认开启，并在新对话首次发送时保存。父会话固定首次展示的子智能体名称、描述、来源路径与启用状态，不提前保存角色提示、模型和权限等未注入内容。新启动时只读取该路径的当前定义，修改后读到最新内容，删除后报不存在；已启动的子会话继续使用自己的配置和历史，冷恢复与 SendMessage 续跑不重新读取定义文件。输入 `@` 或 `/` 可以选择启用的子智能体并插入 `@名称`，发送才委派；菜单选择本身不启动任务。`@` 面板空查询展示全部可用子智能体，输入名称或描述可模糊搜索；上下键切换候选，Enter / Tab 或点击插入，Escape 关闭且保留原文。文件与子智能体分组展示，选择子智能体不会添加文件引用。

“协作提示预设”默认为“默认”；选择“Codex”后使用 Codex 风格的委派提示：仅在用户或适用指令明确要求时使用子智能体，优先自己处理当前阻塞工作，并在委派独立任务后继续其他工作。预设同样在新对话首次发送时保存；协作插件关闭时不可操作，原选择会保留。子智能体页的“Codex 子智能体提示”对应同一个插件选项。

主 Agent 使用 `Agent` 委派，使用 `SendMessage` 沟通，子 Agent 可通过 `RespondToCoordinator` 回复。任务浮窗可以查看进度和日志，停止单个任务，关闭详情标签不删除历史。

子结果在当前完整模型响应和工具批次结束后合入下一次请求。当前运行已经自然结束后才到达的结果保留到后续用户输入，不自动唤醒主任务。自然结束不要求等待所有后台子任务；用户主动停止则会停止所属子任务。

子智能体共享 cwd，并行改同一文件需要自行协调。工具白名单控制可调用工具名，允许 Shell 不等于技术只读。

## 结构化提问

“设置 → 插件”中的“向用户提问”默认开启。Agent 调用 `AskUserQuestion` 后，界面显示选项或文字回答入口。按问题要求填写并提交；暂缓让问题继续保留，停止所属运行会取消相应等待。

问题属于具体会话与请求。切换任务不会把答案提交给另一任务；隐藏辅助面板里的问题也不应阻挡主界面的快捷键。

主任务、辅助对话和子任务的独立状态不代表文件权限隔离。共享资源的行为见[整体设计](../design.md)。
