# 变更审查与文件回退

右侧“审查”用于浏览仓库或任务的改动集合；聊天中的文件 Diff 展示具体轮次或工具操作的变更。

## 选择审查来源

| 来源 | 内容 |
| --- | --- |
| 未暂存 | 工作区变化及可审查的未跟踪文本 |
| 已暂存 | Git 暂存区变化 |
| 全部分支更改 | 上游与 HEAD 的三点比较，没有上游时为空 |
| 上一轮更改 | 当前任务最新轮次的工具快照，非 Git 目录也可使用 |

每个标签保存自己的来源，切换任务不会串用。文件初始折叠，展开时读取内容。手动刷新、任务边界和重新聚焦会触发适用刷新；隐藏标签不持续请求。

普通文本修改可展开未修改区查看完整 before/after。大文件、二进制、快照缺失或特殊 patch 使用降级展示，不能把降级视图当成完整源码。

## 聊天中的 Diff

点击“文件已更改”中的路径，只显示该文件在对应范围的变更；工具卡片使用该次操作补丁，不混入同轮其他操作。相同来源可复用标签，不同任务、轮次、文件或操作保持独立。

轮末摘要统计同一路径首次修改前到最后修改后的净变化；改回原样不会累计中间改动。快照不足时保留文件入口并说明统计不完整。

## 查找、外部打开与显示

审查中的查找在当前来源搜索，按需读取未展开文件。右键可以复制路径、在系统文件管理器定位或在文件树显示。删除文件不提供有效的系统打开入口。

界面设置可调整审查主题、字号、行号和换行；富 Diff 与轻量预览消费的选项范围不同。完整视图可以扩大审查区域并保留对话输入。

## 回退文件

编辑历史消息时可以选择保持当前工作区或使用可用快照回退。程序在写入前比较当前文件与期望状态，遇到并发修改展示冲突。

回退提交失败会尝试恢复本次已经回退的文件，但只恢复仍保持本次回退状态的路径；被其他写者再次修改的文件保留并报告。任务历史分叉和 Git 提交是独立操作，回退不会自动替你提交 Git。

实现：[Git 获取、Diff 降级和回退事务](../internals/review.md)。
