# 面板、标签与浏览器

右侧新标签页提供文件、浏览器、终端、审查和辅助对话入口。标签归属于任务，切换任务会恢复该任务自己的面板状态。

## 标签操作

加号创建新标签，选择内容替换该新标签位置。打开文件可以复用相同来源，导航后重新打开旧来源不会覆盖已经浏览到其他内容的标签。

标签总览支持搜索、切换和恢复最近关闭的标签。关闭当前、其他或全部标签只影响对应任务。浏览器、终端恢复会经过各自的资源创建流程，不能保证关闭前的原生进程仍然存在。

## 浏览器预览

浏览器使用独立原生视图展示网页，可输入地址、后退、前进和刷新。文件预览中的 HTML 源码与浏览器页面是不同入口。

网页与桌面特权页面隔离，导航、窗口打开和快捷键转发由主进程控制。它供用户查看和操作，没有向 Agent 暴露浏览器控制工具。

只有显示中的原生视图需要有效边界。标签隐藏或面板变化时更新原生 bounds，避免网页覆盖其他界面。关闭、主 renderer 重载或崩溃会清理视图。

## 完整视图

默认 Command/Ctrl+Shift+F 切换完整视图。当前对话可以作为额外标签显示；浮动输入框支持收起、展开、最小化和拖动吸附。

主对话和输入框保持同一实例，切换不清草稿或重建全部消息。左栏仍可独立开合和调整宽度，右侧布局保留原分栏偏好。

完整视图隐藏任务顶部栏时，对应任务菜单命令也禁用。返回普通视图恢复可用入口，不补执行之前的按键。
