# 界面显示和通知

界面设置控制主题、文字和代码预览，以及模型性能与用量显示。显示偏好不改变已经发送给模型的上下文。

## 对话展示

助手正文、思考和工具过程分别显示。正文支持 Markdown、代码、表格、数学和 Mermaid；文件与网页链接经过对应打开入口。流式更新逐步显示，长历史按需加载和挂载。

失败重试时，已输出的中断正文可以折叠查看。思考和正文仍按消息身份与阶段保存，不把工具输出混成新的用户消息。选区、消息编辑和查找定位会保留需要的历史内容。

## 主题与预览

界面主题与代码预览主题分别配置。审查提供代码主题、字号、行号和换行偏好，富 Diff 与轻量预览的支持范围由渲染器决定。

终端字体与界面字体独立。系统减少动态效果偏好会影响适用动画，拖动调整面板保持直接响应。

## 模型性能和用量

“显示模型性能与用量”默认开启，放在主对话和辅助对话输入框下方。点击可以查看轮数、模型步骤、时延、输出速度、工具时间和 token 明细。

数值以任务累计，重启不归零；辅助对话只累计自身新增执行。后台记忆用量独立。缺少 usage 或有效计时时不猜测速度和成本。详细统计口径见[诊断原理](../internals/diagnostics.md)。

## 错误提示

输入错误留在当前输入附近，运行失败保存在对应轮次；窗口级操作错误短暂展示，配置错误持续到修复。发送失败不会清掉可重试草稿，过期错误不覆盖新编辑。

模型等待提示表示一段时间没有有效输出，工具执行时间不等同于模型等待。需要停止、立即重试或排查时参见[诊断](diagnostics.md)。

## 通知

“任务通知”由系统内置插件提供，初始启用。“设置 → 常规”的通知开关与“设置 → 插件”共享同一份配置，声音偏好单独保存。应用不在前台时，任务完成、中断或失败可发送系统通知；点击通知定位所属任务。测试模式运行真实业务流程但拦截系统展示和声音。

任务是否装配通知插件取决于首次发送的快照；关闭全局通知会立即抑制系统投递，重新开启不会为原本未装配该插件的任务补上处理器。完整生效范围见[插件](plugins.md#生效范围)。

## 自动标题

系统内置“会话标题”插件为新任务提供临时标题并独立请求简短标题，初始启用。手动命名优先，晚到结果不会覆盖手动标题；生成失败不阻断主回复。可在“设置 → 插件”调整后续新任务是否使用。

原理：[渲染、滚动与显示状态](../internals/rendering.md) · [错误与统计](../internals/diagnostics.md)。
