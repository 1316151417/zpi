# 快捷键

“设置 → 快捷键”统一管理开关、单项录入、清空和恢复默认。修改后点击保存，冲突或系统注册失败时保留原设置。

## 常用默认键

表中的主修饰键为 macOS Command、其他平台 Ctrl。

| 按键 | 动作 |
| --- | --- |
| 主修饰键+N | 新建或切换草稿 |
| 主修饰键+K | 搜索任务、工作区文件和操作 |
| 主修饰键+F | 当前任务查找 |
| 主修饰键+I | 聚焦主任务输入框 |
| 主修饰键+J | 草稿的本地环境菜单 |
| 主修饰键+L | 当前输入框的模型菜单 |
| 主修饰键+U | 已有任务顶部菜单 |
| 主修饰键+[ / ] | 左栏 / 右栏 |
| 主修饰键+1 至 5 | 切换前五个可见置顶任务 |
| 主修饰键+Enter | 立即发送草稿，空草稿时处理队首 |
| 主修饰键+Shift+F | 完整视图 |
| Esc | 优先关闭局部菜单/编辑，再停止运行 |

主窗口全局键为 macOS Control+Command+E，其他平台 Ctrl+Alt+E。后台或最小化时恢复窗口，前台时隐藏；不停止任务。macOS Command+W 隐藏主窗口。

快速浮窗的全局键和内容采集键见[快速对话](quick-chat.md)。实际提示按保存的绑定显示，自定义或清空后不会伪造默认提示。

## 改键和录入

可按命令名称或组合键搜索。录入和按键过滤期间暂停应用命令及全局注册，避免触发原操作；Esc 取消录入，清空只移除绑定。

重复、无效或保留的组合不能保存。恢复默认需要确认，但不会绕过保存步骤。升级补入新命令时，已被自定义占用的默认组合会留空。

## 焦点和弹层

菜单支持方向键、Enter 和 Esc，再按自己的打开快捷键可以关闭。输入法组合输入和长按重复有专门处理。

可见对话框、菜单和问题卡会阻止穿透；隐藏面板中保留的问题不阻挡当前任务。自定义非 Esc 停止键在输入框和终端之前消费，避免插入文字或误触 Shell。

恢复窗口优先保留原焦点，包括辅助输入、终端和浏览器；原目标不可用才回到主输入。显式聚焦命令始终指向当前主任务。

按住 macOS Command 或其他平台 Ctrl 时，前五个置顶任务的位置可显示实际绑定提示，松开恢复时间；问题徽章优先。

原理：[注册事务、事件路由与焦点](../internals/shortcuts.md)。
