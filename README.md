# ZPI

**给 Agent 更少的工具，给你更多的模型选择。**

ZPI 是一个极简的 AI 编码桌面客户端：参考 ZCode 的界面，采用 Pi 风格的 Agent 内核，把「做减法」同时用在工具、界面和工作流上。读代码、改文件、跑命令、看结果——不必先搭建一套复杂的 Agent 平台。

[下载安装](https://github.com/1316151417/zpi/releases) · [项目介绍](http://101.200.240.206/zpi/) · [GitHub](https://github.com/1316151417/zpi)

## 理念：极简不是少做事，而是少干扰

### 四个基础工具，覆盖日常编码

Agent 内核和 SDK 默认只提供四个基础工具：

| 工具 | 用途 |
| --- | --- |
| `read` | 阅读文件和图片，按需加载上下文 |
| `write` | 创建或完整写入文件 |
| `edit` | 精确替换文件中的内容 |
| `bash` | 执行命令、搜索代码、运行脚本和测试 |

内核不为目录浏览等操作不断增加专用工具。已有的命令行和脚本生态，就是 Agent 可以使用的能力；可选的桌面联网工具在内核之外提供。

**四工具是内核的默认边界，不是桌面端的全部能力。** 桌面端通过扩展提供结构化提问、子智能体、联网搜索和后台命令，内核与 SDK 不依赖这些桌面服务。提问、子智能体和联网搜索总开关默认开启，可在「设置 → 插件能力」关闭；设置在新对话首次发送时保存，已有对话保留原有配置。后台命令独立可用。

ZPI 不内置 MCP、专用 REPL 或 Agent 浏览器控制工具。需要浏览器自动化时，Agent 可以编写脚本，通过 `bash` 使用本机已有的运行环境和依赖。客户端的网页预览供人查看结果，不向 Agent 提供浏览器控制接口。

### 界面做减法，模型不做绑定

- **只保留高频工作流**：项目、对话、变更、终端、预览。减少配置负担和界面噪声。
- **模型由你选择**：按任务、成本和使用习惯选择提供商，不把整个工作流锁在一个模型上。
- **没有遥测**：会话和配置保存在本机；模型请求仍会把所需上下文发送给你选择的提供商。
- **代码保持小而清晰**：方便理解、维护和按自己的习惯修改。节省 token 和时间是设计目标，不是未经验证的性能承诺。

## 重要特性

### 1. 多模型接入，同一任务自由切换

预置 **OpenAI（ChatGPT）、DeepSeek、智谱、MiniMax、MiMo**，并区分适用的套餐与按量 API 配置。你也可以自定义提供商的地址、API Key、模型 ID 和能力参数，对接兼容接口的国产模型、其他服务或本地模型服务。

支持三种 API 格式：**OpenAI Chat Completions、OpenAI Responses、Anthropic Messages**。是否可用仍取决于服务端的协议和工具调用兼容性，不是任意模型都能无配置接入。

- 自动初始化预置提供商，手动获取或刷新模型列表。
- 启用、禁用和排序提供商与模型，只显示你常用的选项。
- 按模型选择思考程度，也可在高级配置中自定义推理等级及 CEL 请求参数映射。
- 执行过程中也能更改选择：**当前执行继续使用原配置，后续消息使用新配置**。
- 同一任务可在 ChatGPT Responses 与 Chat Completions 模型之间双向切换，保留文本与工具历史；供应商专有的推理签名只用于对应模型。

### 2. ChatGPT 套餐授权，不用复制网页会话凭据

在「设置 → 模型」选择 **OpenAI（ChatGPT）**，通过浏览器完成 OAuth 登录与套餐访问授权。ZPI 使用授权令牌调用 Responses API，而不是要求你粘贴 ChatGPT 网页 Cookie。

- 登录后获取当前账号的模型目录，支持手动刷新。
- 请求前自动续期令牌；系统加密可用时，凭据加密保存在本机。
- 系统加密不可用时，凭据只保留在当前应用内存，不以明文落盘。
- 完整对话和工具结果保存在本机，便于恢复任务和跨模型续聊。

> 这是 ChatGPT 套餐授权接入，不等同于普通 OpenAI API Key。可用模型、额度及访问资格由账号和 OpenAI 决定；目录中的「待验证」预置模型不代表账号一定有权限。任何第三方客户端都无法承诺「绝不封号」，请遵守提供商条款。

### 3. 从环境变量发现配置，已有设置不被覆盖

如果你已经在开发环境配置了 API Key，ZPI 会在启动时识别以下变量，初始化尚未添加的预置提供商：

| 提供商 | 可识别的环境变量（同一行按顺序取首个有效值） |
| --- | --- |
| DeepSeek | `DEEPSEEK_API_KEY` |
| 智谱 Coding Plan | `ZHIPU_API_KEY` / `ZHIPU_CODING_API_KEY` / `ZAI_CODING_CN_API_KEY` |
| 智谱 API | `ZHIPU_PAYGO_API_KEY` / `ZHIPU_STANDARD_API_KEY` |
| MiniMax Coding Plan | `MINIMAX_API_KEY` |
| MiniMax API | `MINIMAX_PAYGO_API_KEY` |
| MiMo Token Plan | `MIMO_API_KEY` / `XIAOMI_TOKEN_PLAN_CN_API_KEY` |
| MiMo API | `MIMO_PAYGO_API_KEY` / `XIAOMI_API_KEY` |

已有提供商不会被自动发现覆盖，模型目录只在首次初始化或手动刷新时获取。自动发现针对上面的预置变量，不会根据任意环境变量猜测自定义服务。

macOS/Linux 启动时会尝试读取登录 Shell 环境，方便从桌面打开应用时也能发现配置；Windows 使用进程环境。若删除自动导入的提供商但仍保留对应环境变量，下次启动会再次导入。

### 4. 辅助对话：追问，不必打断主任务

主任务正在工作，你想问「这段代码为什么这样改？」或「还有没有另一种方案？」——可以在右侧打开辅助对话。

- 创建时继承主任务已保存的上下文；主任务运行中会包含当前用户消息，不包含尚未完成的助手输出，之后也不持续同步。
- 拥有独立的消息记录、模型选择和运行状态，不把追问写回主任务。
- 可以独立停止或关闭，不中断主任务的执行。
- 不是自动委派的子 Agent，也不会自动接着做主任务。

**辅助对话与主任务共享工作目录，不是文件隔离或只读沙箱。** 提示词要求只有用户在辅助对话中明确请求时才修改工作区；若需要分开代码改动，请使用独立任务的 Git 工作树。工作树隔离检出目录，不限制命令访问本机其他文件。

### 快速对话：随手提问的临时浮窗

- 全局 `Option+Space`（Windows/Linux 为 `Alt+N`）唤起独立浮窗，再按一次收起；`Esc` 在运行中先停止当前回复，停止完成后再按才收起，空闲时直接收起；`Option+Shift+Space`（Windows/Linux 为 `Alt+Shift+N`）开始并显示新对话，只有当前已呈现的空白浮窗再次按下时才收起。回答始终留在浮窗，不跳转主窗口。
- macOS：`Option+Shift+A` 框选截图、`Option+Shift+C` 在当前应用执行复制并带入文字、`Option+Shift+V` 读取剪贴板文字或图片，并打开快速对话。内容追加到当前草稿，保留原文字和图片，确认后才发送；截图按 `Esc` 取消。C 保留复制后的系统剪贴板，沿用来源应用的复制行为（例如 VS Code 无选区时可能复制整行）；复制未更新剪贴板时不会带入旧内容。首次按需申请屏幕录制或辅助功能权限。无选区、复制未更新或剪贴板没有内容时静默结束；权限等错误在浮窗内提示，不弹系统错误框。三组键可在设置中修改、清空或禁用。
- 首次唤起显示 `360 × 44 DIP` 的胶囊输入框及 `28 × 28 px` 圆形发送按钮，没有「＋」。`Enter` 发送，`Shift+Enter` 换行，输入法候选确认不会误发；多行和自动折行使紧凑浮窗向上增长，纯文字最高 `184 DIP`，有图片时最高 `240 DIP`，超过后在输入框内部滚动，删除内容时收缩。发送后展开为 `660 × 560 DIP`，输入框最高 `160 px`；左上「＋」始终新建并保留当次展开；新对话快捷键在已有历史、回复、文字或图片草稿时新建，可见大窗当次保持展开；已呈现且聚焦的空白窗口再次按下才收起。隐藏时新建从紧凑输入框开始；新建尚在检查输入、加载、重置或等待新会话帧时连续按会合并为同一次新建，即使旧大窗仍可见也不取消。原生窗口仍可见但已失焦时，两组快捷键都重新唤起，新建动作保留当次展开。空白大窗收起后再次唤起回到紧凑输入；普通唤起在有文字、图片、待发送/重试内容或对话历史时保留展开和草稿。不设窗口关闭按钮，回复中可停止，不显示模型选择器。
- 可直接粘贴剪贴板里的图片，发送前只显示缩略图，可预览或移除，支持文字配图和纯图片。每条消息最多 8 张，单张源文件最多 10 MiB、4000 万像素，每条消息合计最多 8000 万像素；沿用核心图片校验与处理。图片只在当前临时对话内存中保留，不进入主任务附件或历史。当前消息或历史含图片时，必须使用支持图片的模型。发送失败保留文字和图片，方便重试。
- 浮窗在当前显示器水平居中，底边位于底部 Dock 上方并额外留出约一个 Dock 高度；输入框增高时保留这个底边锚点。侧边或自动隐藏 Dock 使用 64 DIP 间距，小屏会限制尺寸和位置。macOS 使用浮动面板在当前 Space 唤起；通过快捷键或空闲 Esc 主动收起时，焦点回到唤起前的应用，主窗口保持原有显隐状态。失焦或切换 Space 时只收起面板。
- 「设置 → 快速对话」位于子智能体下方，可配置独立的默认模型与思考级别、修改快捷键或直接打开。默认模型从下一次发送起生效，不影响主任务；原配置失效时按提供商/模型顺序使用首个可用模型。「设置 → 快捷键」可分别修改、清除或停用唤起与新建两组全局组合。升级保留已保存的绑定，新默认可在快捷键设置中恢复或手动修改。注册冲突会提示更换，不影响其他仍可用的快捷键。
- 普通收起保留文字、图片草稿与内存对话，不取消回复。距离最后一次接受的发送满 15 分钟后，下次唤起会取消旧回复并回到空白紧凑输入框，清空草稿和图片；收起、唤起和流式回复不续期，尚未发送过消息的会话不按此规则过期。新对话或退出应用后不恢复旧内容，没有历史列表，不写入任务列表或持久会话记录。
- 可用工具直接复用核心 `read`、`bash`，以及已配置且启用的 `web_search` / `web_fetch`，不自动扫描目录。**只读要求依赖系统提示词，并非技术只读沙箱，`bash` 仍可能读写本机文件或联网**。工作基点默认为 `~/Documents/ZPI`，首次发送时若目录不存在会创建；它不限制工具访问其他路径，大命令输出可能写入临时文件。
- 不加载项目指令、技能或命令，不提供独立的 `list` / `search`、`write` / `edit`、结构化提问、子智能体或浏览器控制，也不转为正式任务。模型请求仍会发送给所选提供商。主窗口加载后约 1.5 秒只隐藏预热轻量浮窗入口，不启动模型或 Agent 请求；首次发送再按需加载对话内容。
- 唤起计时诊断默认关闭，可用 `ZPI_QUICK_CHAT_TIMING=1` 开启有界本地记录，不记录消息、文件路径、URL 或模型密钥，也不上传。配置方式、阶段含义及真实 Mac 验收边界见[开发指南](docs/development.md#快速对话的隔离边界)。

### 5. 编码、检查和查看结果，都在一个工作区

- **文件变更**：查看本轮或整个任务的差异；支持消息编辑、重试、任务分叉和带冲突检查的文件回退。
- **右侧面板**：终端、文件和网页预览，不用离开对话查结果。文件与 Diff 共用路径标头和菜单；文本行备注加入对应对话的输入上下文。Markdown/SVG 可切换预览与源码，Mermaid 显示图表，HTML 显示源码；PDF、Word（DOCX/DOC）、Excel（XLSX/XLSM/XLS）、PPTX 和图片/音视频均在面板内只读预览。PPTX 支持缩略图、缩放、元素引用及导出 PDF；右上可使用偏好的已安装编辑器打开。旧 PPT 暂不支持。
- **项目与任务**：任务置顶、归档、恢复和草稿保留；按项目或时间线浏览，按创建或更新时间排序。
- **任务分组**：跨项目自定义分组，七种颜色、内联重命名、折叠和拖拽排序；任务可移入、移出或跨组移动。删除分组只解散归类，保留全部任务；置顶、归档与恢复保留原分组。
- **Git 工作树**：草稿输入框内 `⌘J` / `Ctrl+J` 打开本地环境菜单，↑↓ 移动、→ 展开起始分支、← 返回、Enter 切换工作树开关或确认分支、Esc 关闭并回到输入框。选择本地或远程起始分支（默认当前分支），首次发送时创建游离 HEAD 的独立工作目录，不自动增加本地分支。远程分支使用本地已同步的记录；需要保留为分支时可在工作树中运行 `git switch -c <分支名>`。
- **新建任务**：`⌘N` / `Ctrl+N` 创建或切换到草稿任务，侧边栏按钮显示对应快捷键提示。
- **快速搜索**：`⌘K` / `Ctrl+K` 跨项目查找未归档任务的标题和对话内容，跳到匹配片段；同一入口可查找当前工作区文件和常用操作。
- **任务内搜索**：`⌘F` / `Ctrl+F` 搜索消息与文件变更，高亮定位并加载更早历史。
- **窗口与侧栏**：macOS 全局 `⌃⌘E` 显示/隐藏窗口，Windows/Linux 默认 `Ctrl+Alt+E`；后台或最小化时唤回窗口，前台时隐藏，不中断任务。应用内 `⌘[` / `Ctrl+[` 切换左栏，`⌘]` / `Ctrl+]` 切换右栏。macOS 原有 `⌘W` 隐藏窗口保留。`⌘I` / `Ctrl+I` 主动聚焦当前主任务输入框；全局快捷键恢复窗口时保留原焦点（包括辅助对话、终端和浏览器），仅原目标失效时回退主输入，设置或弹窗打开时不抢焦点。
- **队列与模型**：在当前主对话或辅助对话输入框中，`⌘Enter` / `Ctrl+Enter` 中止当前运行并立即发送队首消息，保留草稿；空队列无操作。`⌘L` / `Ctrl+L` 打开模型菜单，↑↓ 选择模型、→ 展开有效思考档位、← 返回、Enter 确认、Esc 取消，关闭后回到原输入框。
- **置顶切换**：`⌘1`–`⌘5` / `Ctrl+1`–`Ctrl+5` 对应左栏当前置顶顺序，缺位无操作，行内显示快捷键提示。
- **快捷键设置**：设置 → 快捷键可统一开关、录入自定义组合、清除单项或恢复默认，点击保存后持久生效。总开关也控制新建、搜索、查找和 Esc 停止回复，原生复制、粘贴、撤销及菜单导航不受影响。重复、无效或保留组合不能保存；全局键注册失败会保留原设置，录入期间不执行应用命令。
- **上下文管理**：`@` 引用文件、`$` 选择技能；`/init` 建立项目指令，`/compact` 压缩上下文，另有自动压缩与超限恢复。
- **模型性能**：「设置 → 界面设置」的「显示模型性能与用量」默认开启，参考 DeepSeek Harness 在输入框下方居中显示任务累计轮数、步数、平均输出速度、Token 用量和缓存命中率。点击查看时间与用量明细。每次模型请求结束后更新，新一轮发送、任务切换和重启均保留已有累计值。
- **消息排队**：执行时继续补充需求，支持调整、编辑、删除或立即发送排队消息。
- **任务通知**：应用不在前台时，完成、中断或失败可发送系统通知；通知和提示音均可关闭。

技能和项目指令是加载到上下文中的文本，不是一套新的工具平台。支持项目 `AGENTS.md` 及用户/项目级 `.agents`、`.zpi` 资源目录。

图片在尺寸和发送预算内会保留原始字节，包括 EXIF/GPS、作者信息和 PNG 注释，并随图片发给所选模型提供商；需要隐藏这些信息时，请先在本地移除元数据。超限图片可能经过有损压缩，截图小字可能变模糊；WebP 超出预算时会省略。单张附件和整次请求有独立预算，多张附件仍可能在发送时提示合计过大。

### 6. 可选的子智能体插件

子智能体默认开启，可在「设置 → 插件能力」切换。具体配置在「设置 → 子智能体」管理，关闭插件时仍可编辑。

内置 **general-purpose** 与 **Explore**，也可以新增个人或项目级智能体，配置描述、系统提示词、颜色、工具范围和 AGENTS.md 注入。模型可以继承父任务，或单独指定提供商、模型与推理档位。个人配置保存为活动存储 generation 中的 `agents/*.md`，项目配置保存在 `.zpi/agents/*.md`；启用与选择状态保存在 SQLite。

支持并行委派、进度沟通和完成回传。会话右上方的任务浮窗统一显示子智能体与后台命令，可查看执行过程、实时日志和历史记录，或停止单个任务。关闭详情标签不会删除历史。

子智能体共享父任务的工作目录，并行分工应避免同时改写同一文件。它与用户手动打开的辅助对话是两种独立的工作方式。

### 联网搜索与抓取

「设置 → 联网搜索」配置独立的 DeepSeek API Key 并打开提供商启用开关。目前只支持 DeepSeek，同时只启用一个网页服务。「设置 → 插件能力 → 联网搜索」总开关默认开启，同时控制 `web_search` 和 `web_fetch`，升级保留已有显式关闭选择。新对话首次发送时，只有总开关开启、服务已启用且凭据可用才冻结联网能力；后续配置不会给旧对话追加工具。辅助对话和子智能体继承父会话的能力，子智能体的工具白名单和禁用列表仍生效。停用服务或移除 Key 会阻止已有对话继续发出联网请求。

搜索词或目标 URL 会发给 DeepSeek，返回内容会发给当前聊天模型，因此可与其他聊天提供商组合使用。网页 Key 与聊天模型配置独立，不自动复用聊天 Key、原始提问或定位 IP。Key 沿用系统加密凭据存储；加密不可用时仅保留到本次退出。常规设置只返回是否已配置和密钥长度，输入框按实际长度遮蔽。点击眼睛才会临时读取并显示已保存的 Key，可选中复制；隐藏、切换页面、窗口失焦或关闭设置会清除临时显示。仅查看不会修改 Key，输入新密钥可替换，留空或取消编辑会保留原密钥。启停开关、更多菜单和密码输入框与模型配置共用组件；移除 Key 位于更多菜单。

联网工具参考 ZCode，以不可展开的单行过程摘要展示搜索词或目标 URL、状态及来源数，不展示网页正文或来源摘要列表。超长目标文本在行内省略；这不改变持久化结果或模型收到的工具内容。回复操作栏中紧邻「分叉」右侧的「来源」汇总当前轮回复之前成功搜索和抓取的网页，相同 URL 去重；点击浮窗中的短摘要可在内置浏览器打开原文。按钮最多显示 5 个不同站点图标，图标缺失、格式不支持或加载失败时逐项使用联网图标。站点图标仅由主进程从已记录来源的 `site_icon` 安全加载、缩小并转换为 PNG；不会传递网页 API Key 或浏览器 Cookie。网页中的原始 HTML、图片和脚本不会在工具结果或来源摘要中执行或加载。

### 自定义命令

在「设置 → 命令」管理用户级 `~/.zpi/commands` 和项目级 `.zpi/commands` 的 Markdown 命令，支持搜索、启停、新建、编辑、删除和从外部 Agent 显式导入。项目同名命令优先；输入 `/` 可选择命令、技能和此会话启用的子智能体，选择只填入输入框，发送才执行。

命令支持 frontmatter 的 `description`、`argument-hint`、`skills` 和 `disable-noninteractive`，以及 `$ARGUMENTS`、`$1` 等参数。发送命令可能执行模板中的 Shell 片段，请先确认命令内容可信。复制导入独立保存；软链接导入共享源文件，编辑保存会明确提示并要求确认，删除只移除本地链接。文件外部修改可通过刷新或重新聚焦窗口更新，执行前会重新读取。

### 7. 常驻后台命令

桌面端 `bash` 支持 `description`、`run_in_background` 和以**毫秒**为单位的 `timeout`。显式后台命令立即返回任务 ID；普通前台命令默认等待 120 秒（最长 600 秒），超时自动转入后台，单独以 `sleep` 开头的命令则按超时终止。转后台继续使用同一进程，主智能体回合结束或中断不会停止它，适合开发服务、watcher 和长时间构建。

后台命令完成后自动回传结果，可通过 `TaskOutput` 查看或等待输出，通过 `TaskStop` 或浮窗停止按钮清理进程树。停止主任务当前回合不会停止已转后台的命令；停止子智能体会清理它启动的命令。归档、删除会话及正常退出应用会停止所属命令。重启保留任务与日志历史，不自动重启进程，也不会用旧 PID 终止其他进程。

SDK 原生 `bash.timeout` 使用秒，没有桌面后台任务生命周期。工具扩展边界、输出限制和清理行为见 [开发指南](docs/development.md#工具与会话边界)。

## 开始使用

1. 前往 [Releases](https://github.com/1316151417/zpi/releases)，查看当前发布的安装包。
2. 启动 ZPI，在「设置 → 模型」登录 ChatGPT、填写预置提供商 API Key，或添加自定义模型。已有环境变量可自动初始化预置配置。
3. 选择项目和模型，描述你想完成的工作。也可以不选择项目直接对话。
4. 查看变更与预览，必要时打开辅助对话，或切换模型继续任务。

当前桌面构建和本地打包主要在 **macOS Apple Silicon** 上验证。仓库提供 macOS DMG 与 Windows NSIS 打包命令；具体可下载平台以 Releases 为准。

## 本地开发

使用 **Node.js 24 和 npm**。macOS 原生终端模块需要 Xcode Command Line Tools。

```sh
git clone https://github.com/1316151417/zpi.git
cd zpi
npm install --ignore-scripts
npm run install:electron
npm run install:terminal
npm run dev
```

```sh
npm run check                # TypeScript 与 Biome 检查
npm run test:unit            # Node 单元/服务测试，不启动 Electron 或窗口
npm run test:desktop         # 真实 Electron 后台测试；完整套件还需当前 macOS 应用包
npm run test:cleanup         # 验证正常、失败、超时、取消及 worker 崩溃后的清理
npm run test:interactive     # 显式交互测试，会显示窗口和改变焦点，运行前需征得使用者同意
npm run build               # 构建桌面应用
npm run package:mac          # 正式版 macOS DMG
npm run package:mac:preview  # ZPI Preview DMG
npm run package:win          # Windows NSIS 安装包
```

开发客户端以 **ZPI Preview** 身份运行，与打包的 Preview 共用数据目录；正式版使用独立目录。升级 Electron 后需重新运行 `npm run install:terminal`。

本分支将当前设置、项目、任务、草稿、队列与分组保存到 SQLite，会话事实保存到 JSONL v2。旧数据不会在启动时自动读取或迁移。首次试用请使用隔离目录，并先阅读 [存储格式、迁移与回滚限制](docs/specs/sqlite-storage.md)；开发版默认仍使用已有 Preview 数据目录，不能直接当作安全沙盒。

架构保持分层：

```text
packages/ai            模型协议、流式响应、认证与历史兼容
packages/agent         Agent 执行循环
packages/coding-agent  四个工具、会话、上下文、资源与 SDK
packages/ui            共享 React 组件与 Markdown 渲染
packages/desktop       Electron 主进程、preload 与桌面界面
```

调试、数据位置和历史迁移说明见 [开发指南](docs/development.md)。介绍页源码位于 [docs/site/index.html](docs/site/index.html)，部署方式见 [部署说明](docs/deployment.md)。
